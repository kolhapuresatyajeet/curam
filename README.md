# Cúram GP Management

A calm, readable practice operations workspace for Irish GP teams. The interface includes role-aware navigation for GPs, nurses, practice managers, and receptionists, with dashboards for appointments, HealthLink, inboxes, patients, prescriptions, CDM programmes, referrals, billing, Síle AI, insights, staff, workflows, and settings.

## Run locally

```bash
pnpm install
PORT=4173 BASE_PATH=/ pnpm dev
```

The first build uses representative local data so the interface can be explored without external integrations or a database.
